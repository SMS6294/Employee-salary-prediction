# Employee Salary Prediction

A machine learning project that predicts employee salary class using multiple ML algorithms.

## Technologies
- Python
- Pandas
- Scikit-learn
- Streamlit

## Features
- Data preprocessing
- Outlier removal
- Model comparison
- Accuracy visualization
- Streamlit deployment

## Algorithms Used
- Logistic Regression
- Random Forest
- KNN
- SVM
- Gradient Boosting
